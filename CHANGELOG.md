# Changelog

## 1.0.0 (2026-10-08)

- Add `submit_text` to standard Gravity Forms form shortcodes.
- Preserve normal output when the attribute is omitted, empty or invalid.
- Keep overrides inside the rendered embed without saving form changes.
- Support native submit inputs, buttons, and image alternative text.
- Retain behavior attributes, styles, validation results and confirmation handling.
- Carry a signed label through newer AJAX full-form and multipage responses.
- Include isolated regression tests and document the remaining live verification boundary.
